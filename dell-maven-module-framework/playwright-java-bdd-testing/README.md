# playwright-java-bdd-testing

Maven module of **dell-maven-module-framework**.

- **Parent:** `../pom.xml`
- **Tool:** Playwright Java
- **Style:** BDD (Cucumber)
- **Tests:** `src/test/resources/features/`, `src/test/java/`

```powershell
# From parent project root
mvn test -pl playwright-java-bdd-testing

# Or from this folder
mvn test
```
